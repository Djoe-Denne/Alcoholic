# Alcoholic texture packs

Optional texture resolutions for painted machine atlases (engine, malting floor, mash tun).

Each directory is a standalone Minecraft Java 1.19.2 resource pack. Copy the
chosen directory into the instance's `resourcepacks` directory and enable it
above the base Alcoholic resources.

- `Alcoholic-16x`: 16 x 16 lightweight atlas
- `Alcoholic-32x`: 32 x 32 lightweight atlas
- `Alcoholic-128x`: 128 x 128 atlas
- `Alcoholic-256x`: 256 x 256 atlas
- `Alcoholic-512x`: archived full-resolution artwork

The 64 x 64 atlas ships directly with the mod and therefore has no redundant
resource-pack directory here. At this resolution, each material region receives
the equivalent of a 16 x 16 vanilla texture. All derived atlases come directly
from the archived 512 x 512 master, never from another reduced version.
