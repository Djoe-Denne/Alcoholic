# Advancements as Progression Source

Vanilla advancements are the only progression source shipped in the Alcoholic core JAR. A player without FTB still sees the Alcoholic advancement tabs. Detection is written once; [[optional-ftb-quests-chapter]] watches the same IDs.

Tab shape (parents and which process IDs appear) is owned by [[wine-beer-progression-graph]]. Triggers and the rule that vanilla advancements are the detection source stay here.

## Triggers

- Discovery uses `minecraft:inventory_changed`.
- Harvest and process milestones use `alcoholic:crop_harvested` and `alcoholic:process_completed` (defined in `minecraft-common`).
- Artisanal machines remember the last interacting player. When a process completes while that player is offline, the criterion is queued on the block and flushed on the next use of that block.

JSON is generated by extending the Forge-patched 1.19.2 `AdvancementProvider` (`registerAdvancements`). Forge 43.5 has no `ForgeAdvancementProvider` class.

## Original artisanal IDs

`alcoholic:root`, `harvest_grapes`, `harvest_hops`, `produce_must`, `ferment_beverage`, `age_wine`, `blend`, `bottle`. Beer-line IDs live on [[wine-beer-progression-graph]].

FTB Quests 1.19.2 would pull Architectury, FTB Library, FTB Teams, and Item Filters, and loads quests from `config/ftbquests/quests`, not from the mod JAR. That is why the core never depends on FTB.
